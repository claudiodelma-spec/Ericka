# 🏫 Tendita Landy — Sistema de Gestión Escolar + Tienda para Padres

Sistema web integral y PWA para la gestión financiera, administrativa y pedidos de tienda escolar.

> 🧪 **ESTADO:** MODO DEMO / SANDBOX (Datos ficticios, sin conexiones reales a producción).

## 🚀 Estructura del Proyecto
- `/01_requirements`: Especificaciones y reglas de negocio.
- `/02_database`: Modelos de Prisma ORM y scripts de datos DEMO.
- `/03_backend`: Servidor API en Node.js + TypeScript.
- `/04_frontend_admin`: Panel de Control SaaS (Dashboard interactivo con Recharts).
- `/05_frontend_store`: App PWA Mobile First para padres.
- `/06_whatsapp`: Módulo generador de pedidos hacia WhatsApp.
- `/08_tests`: Suite de pruebas automatizadas.

## 🛠️ Instalación y Ejecución Local
```bash
# Instalar dependencias
npm install

# Preparar Base de Datos Sandbox
npx prisma migrate dev --name init
npx ts-node 02_database/seed.ts

# Ejecutar Backend y Frontend
npm run dev
